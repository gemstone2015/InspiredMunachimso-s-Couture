# Gallery Manager v3.1

1. Upload images or videos in Admin > Media Library.
2. Open Admin > Gallery Manager.
3. Create an album and choose Published or Hidden.
4. Click Add media and select reusable Media Library items.
5. Removing an item from an album does not delete the original media.
6. Deleting an album also leaves all original media intact.

Published albums appear in the public "Inside the atelier" section. When no album is published, the original three atelier tiles remain visible.
