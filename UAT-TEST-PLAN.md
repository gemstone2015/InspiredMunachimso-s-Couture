# User Acceptance Test Plan

Run these tests with a fresh browser profile and a mobile phone.

## Visitor

1. Open homepage and navigate every section.
2. Open products, galleries and collections.
3. Test both WhatsApp destinations and phone links.
4. Submit contact, appointment and pre-order forms.
5. Track the created order using its reference and phone.

## Customer

1. Register and log in.
2. Update profile and address.
3. Save measurements.
4. Add and remove wishlist items.
5. Convert a wishlist item to a quotation request.
6. Confirm orders and appointments appear in the portal.
7. Log out and reset the password.

## Administrator

1. Log in and inspect the command centre.
2. Create/edit/archive/delete a product.
3. Upload image and video media.
4. Recycle, restore and permanently delete disposable test media.
5. Manage hero, craft, about/services and business settings.
6. Create a gallery, collection and scheduled campaign.
7. Update order stages and appointment status.
8. Review customers, messages and testimonials.
9. Create and verify a backup.

Record every issue with: page, action, expected result, actual result, screenshot and severity.
